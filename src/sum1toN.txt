        lw      0 1 input    โหลดค่า N (เช่น 5) มาเก็บไว้ใน reg 1
        lw      0 3 neg1     โหลดค่า -1 มาเก็บไว้ใน reg 3
        add     0 0 2        เคลียร์ค่า reg 2 ให้เป็น 0 เพื่อเริ่มเก็บผลรวม (reg 2 = 0 + 0)
loop    beq     1 0 done     (จุดเริ่มลูป) เช็คว่า N == 0 หรือยัง? ถ้าใช่ให้โดดไปที่บรรทัด done
        add     2 1 2        เอาผลรวมเดิมมาบวก N (reg 2 = reg 2 + reg 1)
        add     1 3 1        ลดค่า N ลง 1 (reg 1 = reg 1 + (-1))
        beq     0 0 loop     โดดกลับไปที่บรรทัด loop เพื่อทำซ้ำ
done    halt                 จบการทำงาน
input   .fill   5            กำหนดค่า N = 5 (เปลี่ยนเลขตรงนี้เพื่อทดสอบค่าอื่นได้)
neg1    .fill   -1           ค่าคงที่ -1
