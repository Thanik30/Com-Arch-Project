        add     0 0 1        เคลียร์ reg 1 ให้เป็น 0 (เอาไว้เก็บผลลัพธ์ Result)
        lw      0 2 mcand    โหลดตัวตั้ง (Multiplicand) ใส่ reg 2
        lw      0 3 mplier   โหลดตัวคูณ (Multiplier) ใส่ reg 3
        lw      0 4 bitmas   โหลด Bitmask (เริ่มที่ 1) ใส่ reg 4 เพื่อเอาไว้เช็คบิต
        lw      0 5 bitc     โหลดตัวนับลูป (เริ่มที่ 15) ใส่ reg 5
        lw      0 6 neg1     โหลด -1 ใส่ reg 6 เอาไว้ลดค่าตัวนับลูป

loop    nand    3 4 7        (สเต็ปตรวจบิต) ทำ ~(mplier & bitmask) เก็บใน reg 7
        nand    7 7 7        พลิกบิตกลับอีกรอบให้กลายเป็น (mplier & bitmask) เก็บใน reg 7
        beq     0 7 zero     ถ้า reg 7 == 0 (แปลว่าบิตนั้นเป็น 0) ให้ข้ามไปบรรทัด zero
        add     1 2 1        (ถ้าบิตเป็น 1) เอาตัวตั้งบวกใส่ผลลัพธ์: Result = Result + mcand

zero    add     2 2 2        เลื่อนบิตตัวตั้งไปซ้าย 1 ตำแหน่ง (mcand = mcand * 2)
        add     4 4 4        เลื่อนบิต bitmask ไปซ้าย 1 ตำแหน่ง (เช็คบิตถัดไป)
        add     6 5 5        ลดค่าตัวนับลูปลง 1 (bitcount = bitcount - 1)
        beq     5 0 end      ถ้าตัวนับลูป == 0 แปลว่าทำครบ 15 บิตแล้ว ให้ไปที่ end
        beq     0 0 loop     กระโดดกลับไปทำลูปต่อ

end     halt                 จบการทำงาน ผลลัพธ์สุดท้ายจะอยู่ที่ reg 1
